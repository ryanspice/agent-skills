# Publishing Release Operations

Use when preparing a book or handbook release.

## Workflow

1. Identify source of truth and version.
2. Define edition label, audience, and release artifacts.
3. Split free/public from paid/private.
4. Create artifact manifest.
5. Run export QA.
6. Write release notes.
7. Stage release files and checksum manifest.
8. Archive source inputs and update `.thoughts`.
