# creating-skills

Creates, audits, improves, splits, and packages reusable Hermes-compatible
AI Wiki skills. Covers the full skill lifecycle: intake → design → validation
→ package → install, with progressive-disclosure structure and risk gating.

Universal skill · AI Wiki canonical · v0.1.3

## Quick path

Read `SKILL.md` for instructions. Validator and registry builder live in
`scripts/`. Reference docs are in `reference/`. Templates are in `templates/`.

## Install

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File install-creating-skills.ps1
```
