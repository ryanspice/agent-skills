# Skill Quality Rubric

Score each area 0-2.

| Area | 0 | 1 | 2 |
|---|---|---|---|
| Trigger clarity | vague | usable but broad | precise description with examples |
| Scope | bloated | mostly focused | composable and reusable |
| Instructions | unclear | workable | procedural and concise |
| References | dumped or absent | partly organized | progressive disclosure |
| Tools/scripts | missing or risky | some value | deterministic, documented, safe |
| Security | ignored | partially considered | side effects gated |
| Evals | none | basic | representative regression set |
| Maintainability | hard to edit | okay | clear seams and update loop |

## Interpretation

- 0-5: not ready
- 6-10: usable draft
- 11-14: solid
- 15-16: strong
