# Changelog

## 1.0.0 — 2026-10-16

Initial personal adaptation of Matt Pocock's WAYFINDER. Preserves decision maps,
progressive uncertainty, named references, and bounded resolution. Adds repo-native
orientation, Windows/AI-Wiki conventions, manual routing, single-coordinator ownership,
status/reset/handoff modes, stale-decision checks, and explicit verification boundaries.
Removes mandatory companion skills, assumed 100K-token sessions, automatic research
branch pushes, and compulsory human questioning for code facts. Includes portable
resources, documentation-backed invocation guidance, and evaluation fixtures.

## 1.0.1 — 2026-10-16

run plans; remove stale model-effort ceiling; permit repository-approved shared
checkout claims; normalize machine roots for the owned skills repository; add
explicit optional root bindings to the read-only probe and owned provenance fields.
The 1.0.0 archive is preserved unchanged in the Wiki source archive.

Windows 5.1 probe fix: quiet HEAD lookup preserves an unborn Git repository as
a readable worktree with unknown revision instead of classifying it as a failed probe.
