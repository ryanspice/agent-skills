# Standard execution condition

Implement the supplied specification directly in the assigned repository.
Keep the root route wired throughout the pass. Use only the available file
inspection and editing tools. Do not call a terminal, browser, web service,
MCP tool, process, child agent or delegated model.

Prioritize a coherent, data-driven implementation over commentary. A final
response is not a substitute for repository changes. If the bounded pass ends
before every acceptance item is complete, leave the artifact coherent and
state the exact remaining gaps without claiming completion.
